# Dilleen Dental — Organized HTML/CSS

Open `index.html` in a browser to preview the page.

## CSS structure

- `css/base.css` — variables, reset, layout helpers, buttons, and shared section headings
- `css/header.css` — top bar, navigation, mobile menu, and header responsiveness
- `css/hero.css` — hero content, artwork, badges, and responsive layout
- `css/trust.css` — trust/statistics strip
- `css/services.css` — service cards and service grid
- `css/about.css` — about section and its artwork
- `css/team.css` — team cards and team grid
- `css/funds.css` — health-fund benefits and provider logos
- `css/contact.css` — patient reviews and appointment call-to-action
- `css/footer.css` — footer columns and footer base
- `css/animations.css` — scroll reveal animation

The existing JavaScript remains at the bottom of `index.html` because the requested change was to separate and organize the HTML and CSS.
